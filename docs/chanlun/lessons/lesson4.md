# 缠论讲义第4讲：三类买卖点——商场如战场的进攻时点

上讲我们讲了"多空战场"即中枢，今天我们要讨论在这场"商业战争"中最关键的时刻：**何时进攻，何时撤退？**

就如孙子兵法云：「**知己知彼，百战不殆**」，了解敌我双方的实力和态势还不够，更要知道**在什么时机行动**！

## 一、战争三要：时、地、势

古代打仗，取胜要看三要素：
- **何时开战**（时机把握）  
- **何地开打**（地利优势）
- **如何部署**（战略战术）  

股市操作同样如此：我们要知道**在哪里**（中枢附近）、**如何部署**（买多少卖多少），更重要的——**选择什么时间**进入！

## 二、三类买卖点——进攻撤退的"金科玉律"

缠中说禅发现了市场中三种**100%安全**的时点，就像古代兵法家总结的三个必胜之机：

### 第一类买卖点：背水一战的良机（最危险的反攻时机）

**古代战例**：韩信的"背水一战"——在绝境中发现了敌军的破绽（后路空虚）。
- **股市中**：趋势走到极致，多空力量出现**明显衰竭**（背驰）  
- **进攻良机**：此时趋势力量用尽，新势力有望反攻
- **风险提示**：如同"背水一战"，是绝境反击，需要**极大的勇气** 

```
第一类买点时机：
原来趋势已经走得很远  
         ↓（背驰出现）  
空方力量开始衰竭      
         ↓（确认）
我方力量开始集结  
         ↓
发起反击（买入机会）
```

### 第二类买卖点：以逸待劳的稳妥（巩固反击成果）

**古代战例**：淝水之战，晋军在敌军半渡而击，**稳妥**歼敌。
- **股市中**：第一类买卖点确认后，敌军开始反扑，但**气势已衰**
- **稳妥出击**：在更安全的区间买入，**不急于冒进**  
- **策略优势**：既保证机会，又**避免急进的风险**

### 第三类买卖点：趁胜追击的机会（确认大势已定）

**古代战例**：赤壁之战，曹操大败，孙刘联军乘胜追击。
- **股市中**：多方明显突破原来势力范围（中枢被打破）
- **确认时机**：胜负已经明朗，**顺势而为更加确定**
- **追击败军**：市场格局已经清楚转换，加大投入

```
第三类买点确认：
中枢区间被打破  
       ↓
多方取得明显优势
       ↓（市场确认）  
跟进建仓（更安全）
```

## 三、商场战术分解

### 1. 勇猛精进——第一类买卖点

> 就像商场老大被新秀挑战，老大的实力看似强大但在某些环节已显疲态。此时新秀敢于在老大虚弱处发起攻势，这是非常有**胆略和眼光**的行为。

**操作要领**：
- 要有**敏锐的洞察力**：看到老大的力量衰竭
- 要有**果断的决心**：敢于第一时间出手  
- 要有**足够的准备**：资金随时就位（如同士兵早已集结）

### 2. 稳健经营——第二类买卖点

> 就如一位智慧的CEO，不急于在市场初期冒进，而是等待时机，等竞争格局清晰后再加大投入进行拓展。

**操作要领**：
- **观察市场验证**：等待第一类点的效果证实
- **寻找稳妥时机**：在风险明显降低时入手
- **稳步布局**：避免急功近利，稳扎稳打

### 3. 顺势扩张——第三类买卖点

> 市场已经明显转向，聪明的投资者会**顺应大势，加大投入**，分享市场转换后的收益。

**操作要领**：
- **识别新格局**：明确新的发展趋势
- **抓住机遇窗口**：在确认时快速行动
- **扩大战果**：顺应潮流，乘胜追击

## 四、攻防转换的艺术

商场如战场，**攻守时机**随时转换：

- 原来的**强势方**，在持续进攻后变得虚弱（背驰出现 → 第一类卖出点）
- 原来的**弱势方**，在持续低迷后积蓄力量（反向背驰 → 第一类买入点）
- 整个过程呈现**循环变化**特征

### 点位与力量的相互验证
- 第一类：力量变化的**首次确认**
- 第二类：力量变化的**二次验证**  
- 第三类：力量变化的**最终确认**

如同武打片的：**起势 → 进击 → 定局**三段动作。

## 五、三种"兵法"的心法差异

1. **第一类**：如侠客之敢勇，见机即行，**胆识为先**
2. **第二类**：如将军之沉着，审时度势，**稳健为本**  
3. **第三类**：如枭雄之敏锐，顺时而动，**机变为王**

> 武侠小说中有剑宗和气宗之别，剑宗重招式（时机），气宗重内功（心态）。三类买卖点如同三类"兵器"，各有其妙用！

## 六、实战中的时机选择

选择哪类买卖点，如同选择作战方案：

- **性格偏急进者**：偏好第一类（敢于冒险，收益或风险都最大）
- **性格偏稳重者**：多用第二类（稳妥安全，收益确定性高）  
- **性格偏灵活者**：善用第三类（顺势而为，跟随趋势）

> 就如三国人物：关羽"千里走单骑"（第一类），诸葛亮"七擒孟获"（第二类），曹操"顺天应人"（第三类）

## 总结与思考

今天我们学习了"商场如战场"中的**进攻艺术**：
- 第一类是**逆势而动**的勇敢出击
- 第二类是**稳健跟随**的安全确认  
- 第三类是**顺势跟进**的及时扩大

想象你是古代一位军事谋士，面对一场正在进行的战役：敌军主力攻势已显疲态，但己方尚未发起反击，此时你会建议主帅采用何种作战时机？这种战略分析思路与三类买卖点判断有何相通之处？

下讲我们将探讨：**背驰**——这场商业战争的关键转折信号如何识别？这是判断第一类买卖点的**核心技能**！
