# 缠论系列讲义目录

## 理论篇（第1-6讲） 

### [第1讲：股市如流水，走势终完美](./lessons/lesson1.md)
- 用河水流向比喻三大走势类型
- 阐述走势终完美原理
- 解析不患与患的辩证关系

### [第2讲：K线分型如山水，笔段构造似桥梁](./lessons/lesson2.md) 
- 用山脉地形类比分型概念
- 比喻笔段如山间路径构建
- 解释包含关系与地理制图

### [第3讲：中枢如战场，多空博弈场](./lessons/lesson3.md)
- 把中枢比作主战场区域
- 用足球赛事解释多空力量

### [第4讲：三类买卖点——商场如战场的进攻时点](./lessons/lesson4.md)
- 用古代兵法解释三类买卖点

- 探讨攻守转换艺术

### [第5讲：背驰如弦断——力度衰竭的识别艺术](./lessons/lesson5.md)
- 用射箭力度衰竭比喻背驰
- 解析登山负重的动能变化  
- 运用音乐和生活实例阐释

### [第6讲：级别如天地，时空交融的博弈格局](./lessons/lesson6.md)
- 从宇宙层次解读级别概念

- 探讨级别共振与实战应用
