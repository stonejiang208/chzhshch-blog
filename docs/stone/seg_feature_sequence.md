# 线段划分的特征序列法

> 来源：缠中说禅博客第67-83课 + chan.py (Seg/) 代码实现

## 1. 线段的定义

线段是至少由**三笔**构成的一段走势。线段的方向由其**第一笔**的方向决定：
- 以向上笔开始的线段 → **向上线段**
- 以向下笔开始的线段 → **向下线段**

### 线段的基本要求

```
线段 = 至少3笔（同方向）+ 方向一致
```

- 线段**不能**从底到底或从顶到顶（起点和终点方向必须一致）
- 线段**必须**被另一个线段破坏才算真正结束

## 2. 特征序列的概念

### 2.1 什么是特征序列

**特征序列**是将线段中的笔按照方向分类后的序列，用于判断线段是否被破坏。

| 线段方向 | 特征序列方向 |
|---------|-------------|
| 向上线段（以向上笔开始） | **向下**特征序列 |
| 向下线段（以向下笔开始） | **向上**特征序列 |

**关键理解**：特征序列的方向总是与线段方向相反。

### 2.2 特征序列的元素

以向上线段为例，其特征序列由所有**向下笔**构成：
```
向上线段：↑ ↓ ↑ ↓ ↑ ↓ ↑ 
           ↓   ↓   ↓   ↓    ← 特征序列（向下笔）
```

每个向下笔都是特征序列的一个"元素"。

### 2.3 标准特征序列

在进行分型判断前，需要先对特征序列进行**非包含处理**（与K线包含关系处理相同）。

## 3. 特征序列的分型

### 3.1 分型类型

| 线段类型 | 关注分型 | 判定依据 |
|---------|---------|----------|
| 向上线段 | **顶分型** | 特征序列出现顶分型 → 线段结束 |
| 向下线段 | **底分型** | 特征序列出现底分型 → 线段结束 |

### 3.2 特征序列分型的构成

特征序列分型同样由**三根元素**（笔）构成：
- **顶分型**：中间元素高点最高、低点也最高
- **底分型**：中间元素低点最低、高点也最低

## 4. 线段划分的两种情况

这是线段划分的核心，需要根据特征序列分型中**第一与第二元素间是否有缺口**来判定。

### 4.1 第一种情况：存在缺口

**特征**：特征序列的第一元素与第二元素之间**存在缺口**（没有重合区间）。

```
情况一判定规则：

向上线段顶分型：第1笔高点 < 第2笔低点 → 线段在顶分型高点结束
向下线段底分型：第1笔低点 > 第2笔高点 → 线段在底分型低点结束
```

**图形示意**（向上线段第一种情况）：
```
特征序列：  ↓  ↓  ↓
           1  2  3
           ─┐  ┌─  ← 缺口存在
            └─┘
           顶分型成立 → 线段结束
```

### 4.2 第二种情况：不存在缺口

**特征**：特征序列的第一元素与第二元素之间**没有缺口**（有重合区间）。

```
情况二判定规则：

向上线段：需要观察"第二特征序列"（反向笔的序列）
          如果第二特征序列出现底分型，则线段结束

向下线段：需要观察第二特征序列
          如果第二特征序列出现顶分型，则线段结束
```

### 4.3 两种情况的区别

| 情况 | 缺口 | 判定方式 | 线段结束条件 |
|------|------|----------|-------------|
| **第一种** | 有 | 直接看特征序列分型 | 顶/底分型直接确认结束 |
| **第二种** | 无 | 需要看第二特征序列 | 特征序列分型 + 第二特征序列分型 |

**关键区别**：
- 第一种情况：线段转折力度**强**，无需观察反向走势
- 第二种情况：线段转折力度**弱**，需要反向走势确认

## 6. 线段划分的边界条件

### 6.1 第一条线段的方向确定

第一条线段的方向由**首次出现的特征序列分型**决定，而非第一个出现的笔。

### 6.2 线段破坏的传递性

- 线段破坏可以**逆时间传递**：被后一线段破坏的线段，一定破坏前一线段
- 如果某线段破坏了前一线段，那么它也破坏了更前的线段

### 6.3 特殊情况：笔破坏但未线段破坏

线段可能只被**笔破坏**（第一种情况的笔破坏），但最终没有发展为**线段破坏**。这种情况会导致"古怪线段"。

```
特征：笔破坏后未能形成特征序列分型
结果：线段延续，原线段未被真正破坏
```

## 7. 算法流程总结

```python
def 划分线段(bi_list):
    1. 初始化向上/向下特征序列容器
    2. 遍历笔：
       a. 根据笔方向加入对应特征序列
       b. 检查特征序列是否形成分型
       c. 如果形成分型：
          - 检查第一、二元素间是否有缺口
          - 有缺口 → 情况一 → 线段结束
          - 无缺口 → 情况二 → 检查第二特征序列
    3. 标记线段起止点
    4. 更新父线段属性
```
