## 🎯 学习前必读
### 什么是缠论？
缠论全称「缠中说禅走势中枢理论」，是由新浪博客博主「缠中说禅」（人称缠师）在2006-2008年期间发表的108篇股市教程，是一套完整的、自成体系的市场走势分析理论，完全基于市场走势的客观规律，没有任何主观假设，是目前国内最具影响力的证券分析理论之一。

### 学习要求
1. **完全开放的心态**：不要用你之前学过的任何技术分析理论来套缠论，先清空自己，完全接受缠论的定义
2. **重视基础概念**：分型、笔、线段、中枢是整个理论的基石，必须100%掌握，不要急于学买卖点
3. **多画图多练习**：至少手动画出100张以上的走势图，才能真正理解走势的递归结构
4. **结合实战**：学完一部分内容就去实盘验证，不要纸上谈兵

**🔴 背驰核心概念（重要更新 2026-04-12）：**

**缠师原文定义**（第 17 课思考题）：
> 背驰是两相邻同向趋势间，后者比前者的走势力度减弱所造成的。

**关键要点**：
1. **前提条件**：必须存在两个相邻的同向趋势（每个趋势至少包含 2 个同向中枢）
2. **比较对象**：比较的是两个趋势的**离开段**力度，不是进入段
   - 标准上涨趋势结构：`a+A+b+B+c`
   - ✅ 背驰比较：**c 段 vs b 段**（最后两段同向走势）
   - ❌ 错误理解：c 段 vs a 段
3. **力度指标**：可用 MACD 面积、均线斜率、成交量、时间长度等判断
4. **背驰信号**：后一段创新高/低 + 力度减弱 = 背驰完成

**背驰判断流程**：
```
1. 识别中枢数量 → 2 个以上同向中枢 = 趋势
2. 确认趋势结构 → a+A+b+B+c
3. 比较力度 → c 段 vs b 段（MACD 面积比较）
4. 背驰确认 → c 段创新高 + MACD 面积减小
```

**示例**（日线上涨趋势背驰）：
```
结构：a(30 分钟)+A(日线)+b(30 分钟)+B(日线)+c(30 分钟)
比较：c 段 MACD 红柱面积 < b 段 MACD 红柱面积
信号：c 段创新高 + 面积减小 → 日线上涨趋势背驰完成
```

## ❌ 常见学习误区
1. **跳过基础直接学买卖点**：这是最常见的误区，基础不牢，后面学的都是空中楼阁
2. **追求精确划分**：不要纠结于某些特殊走势的笔和线段划分，理解原理比精确划分更重要
3. **迷信指标**：缠论本身不需要任何指标，MACD只是辅助判断背驰的工具，不要本末倒置
4. **预测市场**：缠论是用来当下判断走势的，不是用来预测的，不要试图用缠论预测未来走势
5. **机械操作**：缠论是活的，不是数学公式，要根据当下的走势灵活运用
