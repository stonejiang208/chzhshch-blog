# 中枢构建算法

> 来源：缠中说禅博客 + chan.py (ZS/) 代码实现

## 1. 中枢的定义

### 1.1 数学定义

**中枢**是某级别走势类型中，至少由**三个次级别走势类型**重叠所构成的区域。

```
中枢 = 三个次级别走势类型（笔或线段）的重叠区间
```

### 1.2 图形定义

```
        高点
         │
    ┌────┼────┐
    │    │    │
    │  中枢区间  │  ← ZG ~ ZD
    │    │    │
    └────┼────┘
         │
        低点
```

**中枢区间**：
- **ZG**：中枢的最高点（highest low）
- **ZD**：中枢的最低点（lowest high）
- **ZZ**：中枢中点 = (ZG + ZD) / 2

### 1.3 关键性质

1. **重叠构成**：至少三段次级别走势重叠
2. **区间唯一**：ZG ≥ ZD（向上中枢ZG>ZD，向下中枢ZG=ZD的例外）
3. **方向一致**：向上中枢ZG>ZD，向下中枢ZG<ZD

## 2. 中枢的构成

### 2.1 笔中枢 vs 线段中枢

| 类型 | 构成元素 | 最小级别 |
|------|---------|----------|
| **笔中枢** | 笔（至少3笔） | 笔级别 |
| **线段中枢** | 线段（至少3段线段） | 线段级别 |

**重要约束**：笔**不能**构成中枢，线段是构成中枢的**最小单位**。

### 2.2 中枢的构成方式

```
上涨走势：上+下+上 → 第三个上的低点构成中枢
         ↓
    ┌─┐ ┌─┐ ┌─┐
   ╱   ╲   ╲
  ─     ─   ─
        ↑
       中枢区间（由三个回调的低点重叠构成）

下跌走势：下+上+下 → 第三个下的高点构成中枢
         ↑
    ─   ╱   ╲   ╲
     ╲ ╱     ╲
      ┘       └
        ↑
       中枢区间（由三个反弹的高点重叠构成）
```

### 2.3 chan.py 实现

```python
# chan.py/ZS/ZS.py
class CZS(Generic[LINE_TYPE]):
    def __init__(self, lst: Optional[List[LINE_TYPE]], is_sure=True):
        # lst: 构成中枢的笔或线段列表（至少3个）
        self.__begin = lst[0].get_begin_klu()
        self.__begin_bi = lst[0]
        
        # 中枢区间：由所有笔/线段的极值重叠构成
        self.__low = max(bi._low() for bi in lst)   # ZG：最高低点
        self.__high = min(bi._high() for bi in lst) # ZD：最低高点
        self.__mid = (self.__low + self.__high) / 2
        
        # 中枢涉及的极值范围
        self.__peak_high = max(bi._high() for bi in lst)
        self.__peak_low = min(bi._low() for bi in lst)
```

## 3. 中枢的级别

### 3.1 级别定义

中枢的级别由其**构成元素**的级别决定：

| 中枢类型 | 构成元素 | 级别 |
|---------|---------|------|
| 笔中枢 | 笔 | 笔的级别（由K线周期决定） |
| 线段中枢 | 线段 | 线段的级别 |
| 走势中枢 | 走势类型 | 走势类型级别 |

### 3.2 级别递归

```
K线 → 分型 → 笔 → 线段 → 走势类型 → 中枢 → ...
                ↓
         线段构成线段级别中枢
```

**重要**：中枢的级别 = 构成它的走势的**次级别**。

### 3.3 级别对应

| K线周期 | 笔级别 | 线段级别 |
|--------|-------|---------|
| 1分钟 | 1分钟笔 | 1分钟线段 → 5分钟中枢 |
| 5分钟 | 5分钟笔 | 5分钟线段 → 30分钟中枢 |
| 日线 | 日线笔 | 日线线段 → 周线中枢 |

## 4. 中枢的识别算法

### 4.1 基本流程

```
输入：笔/线段列表
      ↓
寻找方向相反的三段走势
      ↓
检查三段的重叠区间
      ↓
┌─────────────────┐
│ 重叠区间存在    │ → 中枢成立
│ (ZG ≥ ZD)      │
└─────────────────┘
```

### 4.2 判定条件

```python
# chan.py/ZS/ZSList.py

    """查找中枢"""
    # 1. 寻找方向相反的三段
    # 2. 计算重叠区间
    # 3. 如果重叠区间存在，中枢成立
```

**中枢成立条件**：
1. **数量**：至少3段同向走势（方向：上-下-上 或 下-上-下）
2. **重叠**：第三段与第一段/第二段有重叠区域
3. **方向**：中枢方向与构成走势方向一致

### 4.3 中枢的唯一性

- 同一位置可能有多个中枢（嵌套或重叠）
- 中枢区间可能扩展或延伸
- 需要用**走势必完美**来约束

## 5. 中枢的延伸与破坏

### 5.1 中枢延伸

中枢延伸：中枢区间没有被破坏，继续围绕中枢区间震荡。

```python
# chan.py/ZS/ZS.py
def in_range(self, item):
    """检查笔/线段是否在中枢范围内"""
    return item._low() <= self.high and item._high() >= self.low
```

**延伸条件**：
- 所有次级别走势都回到中枢区间
- 没有出现第三类买卖点

### 5.2 中枢破坏

中枢破坏的充要条件：**出现第三类买卖点**。

| 破坏类型 | 条件 | 结果 |
|---------|------|------|
| **第三类卖点** | 向上中枢后向下跌破ZD | 中枢破坏 |
| **第三类买点** | 向下中枢后向上突破ZG | 中枢破坏 |

### 5.3 中枢扩展

中枢扩展：中枢延伸过程中，中枢区间扩大。

```python
# chan.py/ZS/ZS.py
def combine(self, zs2, combine_mode='zs'):
    """合并两个中枢"""
    if combine_mode == 'zs':
        # 中枢区间重叠则合并
        if has_overlap(self.low, self.high, zs2.low, zs2.high, equal=True):
            self.do_combine(zs2)
```

## 6. 走势必完美与中枢

### 6.1 走势必完美

> 任何走势类型完成后，都必然转化为其他走势类型。

对于中枢：
- 中枢完成后 → 必然转化为上涨/下跌/盘整
- 盘整完成后 → 必然产生同级或更大级别的中枢

### 6.2 操作意义

```
中枢完成后 → 必然出现第三类买卖点
         ↓
观察第三类买卖点 → 决定操作方向
```

### 6.3 中枢震荡监视器

**Z（中枢中轴）**：
- Z = (ZG + ZD) / 2
- 震荡在Z之上 → 偏强
- 震荡在Z之下 → 偏弱

**Zn（次级震荡区间中轴）**：
- 用于判断中枢震荡的强弱
- Zn在Z之上越多 → 震荡越强

## 7. 中枢相关概念

### 7.1 中枢震荡

中枢区间内的价格波动，**没有**出现第三类买卖点。

```
中枢震荡操作：
- 在中枢下沿买，上沿卖
- 等待第三类买卖点出现
```

### 7.2 趋势与中枢

| 趋势类型 | 中枢数量 | 说明 |
|---------|---------|------|
| 上涨 | ≥1个 | 至少一个中枢 |
| 下跌 | ≥1个 | 至少一个中枢 |
| 盘整 | 1个 | 只有一个中枢 |

### 7.3 类中枢

笔构成的结构类似中枢但不是正式中枢（笔不能构成中枢）。

## 9. 实战应用

### 9.1 中枢操作策略

| 状态 | 操作 |
|------|------|
| 中枢上移 | 持股，等待第一类卖点 |
| 中枢下移 | 持币，等待第一类买点 |
| 中枢震荡 | 高抛低吸 |
| 中枢破坏 | 根据第三类买卖点操作 |

### 9.2 中枢与买卖点

- **第一类买卖点**：背驰点，发生在中枢前后
- **第二类买卖点**：中枢震荡中的高低点
- **第三类买卖点**：中枢破坏点
