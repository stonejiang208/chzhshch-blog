# 笔的算法规范

> 来源：缠中说禅博客原文 + chan.py (C2-chanlun-v2) 代码实现

## 1. 笔的定义

笔是缠论中最基础的走势单元，由**顶分型**和**底分型**以及连接它们的**至少一根K线**组成。

### 1.1 笔的构成条件

```
笔 = 顶分型 + 向下笔 + 底分型
```

具体条件：
1. **必须有顶分型和底分型**：顶分型的高点 > 底分型的低点
2. **顶分型与底分型之间至少有一根K线**：排除相邻的分型
3. **方向统一**：向上笔的起点是底分型的低点，终点是顶分型的高点；向下笔相反
4. **顶分型和底分型不能共用K线**：相邻的顶底分型之间必须有独立的K线

### 1.2 笔的方向

| 笔的方向 | 起点 | 终点 | 特征序列方向 |
|---------|------|------|-------------|
| **向上笔** | 底分型低点 | 顶分型高点 | 向下 |
| **向下笔** | 顶分型高点 | 底分型低点 | 向上 |

## 2. 分型处理

### 2.1 分型的定义

**顶分型**：三根K线组成，第二根K线的高点是三根K线中最高的，第二根K线的低点也是三根K线中最高的。
```
    ┌─┐
  ┌─┘ └─┐
─┘       └─
(第1根) (第2根) (第3根)
```

**底分型**：三根K线组成，第二根K线的低点是三根K线中最低的，第二根K线的高点也是三根K线中最低的。
```
─      ┌─
  └─┐ ┌─┘
    └─┘
(第1根) (第2根) (第3根)
```

### 2.2 包含关系处理

当相邻K线存在包含关系时，需要进行**非包含处理**（合并处理）。

**包含定义**：两根K线满足以下任一条件：
- 前一根的高点 = 后一根的高点，且前一根的低点 ≤ 后一根的低点（向上走势）
- 前一根的高点 ≥ 后一根的高点，且前一根的低点 = 后一根的低点（向下走势）

**处理规则**：
1. **向上走势**：取两根K线中高点的较高者、低点的较高者，合并为新K线
2. **向下走势**：取两根K线中高点的较低者、低点的较低者，合并为新K线

**处理顺序**：从左到右依次处理，处理后的结果继续与后续K线比较。

    def __init__(self, idx: int, klu_start: CKLine_Unit, klu_end: CKLine_Unit,

## 3. 笔的确定性与不确定性

### 3.1 确定笔 vs 未完成笔

| 状态 | 条件 | 说明 |
|------|------|------|
| **确定笔** | 顶分型 + 至少一根向下笔 + 底分型 | 笔已完成，可进入线段分析 |
| **未完成笔** | 只有顶分型或只有底分型 | 笔方向未最终确认，等待后续确认 |

### 3.2 笔的延伸与破坏

- **笔的延伸**：笔形成后，延续原方向继续发展
- **笔的破坏**：出现反向分型，原笔结束

**关键规则**：笔**只能被笔破坏**，线段不能直接破坏笔。

## 4. 笔定理

### 4.1 缠中说禅笔定理

> 任何当下，在任何时间周期的K线图中，走势必然落在确定的具有明确方向的笔当中（向上笔或向下笔），而在笔當中的位置，必然只有两种情况：
> 1. 在分型构造中
> 2. 分型构造确认后延伸为笔的过程中

### 4.2 笔状态编码

用二元组表示当下笔的状态：
- `(1, 1)` - 向上笔在延伸中
- `(-1, 1)` - 向下笔在延伸中
- `(1, 0)` - 向上笔出现顶分型构造
- `(-1, 0)` - 向下笔出现底分型构造

## 5. 算法要点

### 5.1 处理流程

```
K线序列 → 非包含处理 → 识别分型 → 构建笔 → 更新笔列表
```

### 5.2 边界条件

1. **第一笔的方向确定**：第一个出现的分型决定了第一笔的方向
2. **笔的最小长度**：至少需要3根K线（顶分型3根 + 底分型3根，但中间可有重叠）
3. **笔的连续性**：连续同向笔之间不能有其他笔插入
