# 买卖点算法

> 来源：缠中说禅博客 + chan.py (BuySellPoint/) 代码实现

## 1. 三类买卖点概述

| 买卖点 | 名称 | 位置 | 判定条件 |
|-------|------|------|----------|
| **第一类买卖点** | 背驰点 | 中枢前后 | 趋势背驰 |
| **第二类买卖点** | 中枢震荡点 | 中枢内部 | 触及中枢边界 |
| **第三类买卖点** | 中枢破坏点 | 中枢前后 | 离开中枢后回调/反弹不触及中枢 |

## 2. 第一类买卖点

### 2.1 定义

**第一类买卖点**是趋势背驰后形成的买卖点，发生在**趋势的最后一个中枢**前后。

```
上涨趋势背驰 → 第一类卖点
下跌趋势背驰 → 第一类买点
```

### 2.2 判定条件

1. **趋势形成**：至少有两个同级别中枢
2. **背驰发生**：创新高/新低但力度减弱
3. **转折确认**：回拉触及前中枢

### 2.3 背驰的量化

chan.py 中背驰的计算方式：

```python
# chan.py/Seg/Seg.py
def Cal_MACD_slope(self):
    """MACD斜率法"""
    begin_klu = self.get_begin_klu()
    end_klu = self.get_end_klu()
    if self.is_up():
        return (end_klu.high - begin_klu.low) / end_klu.high / (end_klu.idx - begin_klu.idx + 1)
    else:
        return (begin_klu.high - end_klu.low) / begin_klu.high / (end_klu.idx - begin_klu.idx + 1)

def Cal_MACD_amp(self):
    """MACD幅度法"""
    begin_klu = self.get_begin_klu()
    end_klu = self.get_end_klu()
    if self.is_down():
        return (begin_klu.high - end_klu.low) / begin_klu.high
    else:
        return (end_klu.high - begin_klu.low) / begin_klu.low
```

**背驰判定**：
```
背驰 = 创新高/新低 + MACD面积/斜率缩小
```

## 3. 第二类买卖点

### 3.1 定义

**第二类买卖点**是中枢震荡过程中触及中枢边界形成的买卖点。

```
向上中枢：触及ZD → 第二类买点
向下中枢：触及ZG → 第二类卖点
```

### 3.2 判定条件

1. **中枢存在**：已形成中枢
2. **触及边界**：价格触及ZG或ZD
3. **未破坏中枢**：没有出现第三类买卖点

### 3.3 图形示意

```
向上中枢（ZG > ZD）：
        ZG ──────────────
                ┌─────┐
                │中枢 │
                └─────┘
              ↑        ↑
            ZD       第二类买点（触及ZD）
```

### 3.4 操作特点

- **安全系数高**：在中枢内部，相对确定性
- **非效率最优**：可能错过大幅行情
- **适合震荡市**：中枢震荡时的主要操作点

## 4. 第三类买卖点

### 4.1 定义

**第三类买卖点**是中枢破坏后形成的买卖点。

```
向上中枢第三类卖点：上涨离开中枢后，向下跌破ZD
向下中枢第三类买点：下跌离开中枢后，向上突破ZG
```

### 4.2 判定条件

1. **中枢完成**：中枢已形成
2. **离开中枢**：向上突破ZG或向下突破ZD
3. **回试不破**：回调/反弹不回到中枢区间

```
第三类卖点 = 中枢上移离开 + 回调跌破ZD
第三类买点 = 中枢下移离开 + 反弹突破ZG
```

### 4.3 图形示意

```
第三类卖点示例：
            ┌─────┐  → 向上离开
            │中枢 │      ↓
            └─────┘        ╲
              ↑              ╲
             ZD ──────────────跌破→ 第三类卖点
```

### 4.5 操作意义

| 第三类买卖点 | 强度 | 操作建议 |
|-------------|------|----------|
| 第三类买点 | 强 | 积极介入 |
| 第三类卖点 | 强 | 立即退出 |

**注意**：
- 第三类买卖点是**效率最高**的买卖点
- 出现第三类买卖点，中枢被破坏，走势可能终结

## 5. 三类买卖点关系

### 5.1 位置关系

```
第一类买卖点 ← 中枢前 → 第二类买卖点 ← 中枢后 → 第三类买卖点
     ↑                                    ↑
   背驰点                               破坏点
```

### 5.2 转化关系

```
第一类买卖点后 → 可能形成第二类买卖点
第二类买卖点后 → 可能形成第三类买卖点
第三类买卖点后 → 原走势类型结束
```

### 5.3 操作优先级

| 优先级 | 买卖点 | 确定性 | 效率 |
|-------|-------|--------|------|
| 1 | 第三类买卖点 | 高 | 高 |
| 2 | 第一类买卖点 | 高 | 中 |
| 3 | 第二类买卖点 | 中 | 低 |

## 6. 背驰的深入分析

### 6.1 背驰的类型

| 类型 | 特点 | 判定 |
|------|------|------|
| **趋势背驰** | 标准背驰，两个中枢后的背驰 | 最可靠 |
| **盘整背驰** | 盘整中的背驰 | 需结合中枢 |
| **小转大** | 小级别背驰引发大级别转折 | 需预防 |

### 6.2 背驰的量化指标

```python
# chan.py/Common/CEnum.py
class MACD_ALGO(Enum):
    SLOPE = auto()  # 斜率法
    AMP = auto()    # 幅度法

# 在线段/笔中使用

```

### 6.3 背驰的辅助判断

- **均线**：辅助判断支撑/压力
- **成交量**：背驰时成交量萎缩
- **MACD**：柱子面积缩小

## 7. 特殊买卖点

### 7.1 类买卖点

笔级别或更小级别的买卖点，判定方法相同但级别更小。

### 7.2 二次买卖点

第二类买卖点的特殊形式：
- **第二类买点与第三类买点合一**：最强走势
- **第二类卖点与第三类卖点合一**：最弱走势

## 9. 实战应用

### 9.1 操作策略

| 走势阶段 | 最佳买卖点 | 策略 |
|---------|-----------|------|
| 趋势启动 | 第三类买点 | 追涨 |
| 趋势背驰 | 第一类买卖点 | 逃顶/抄底 |
| 中枢震荡 | 第二类买卖点 | 高抛低吸 |

### 9.2 级别选择

- **大级别**（日线以上）：第一类、第三类买卖点
- **小级别**（30分钟以下）：第二类买卖点、中枢震荡

### 9.3 止损设置

| 买卖点 | 止损位 |
|-------|--------|
| 第一类买点 | 最近中枢下沿 |
| 第二类买点 | 中枢ZD |
| 第三类买点 | 突破ZG后的回调低点 |
